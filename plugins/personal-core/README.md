# Personal Core Rules

跨项目通用协作规范与知识治理插件（纯净跨平台版），只包含零环境绑定的方法论与工作纪律，适合直接部署到全新电脑的 Antigravity 环境中。

## 包含内容

- `rules/AGENTS.md`：插件启用即常驻生效的全局约束（控制在 5 KB 以内），涵盖：
  - 沟通风格与决策口径（简体中文、少追问带假设推进、高风险确认边界）
  - 工程与交付纪律（轻量 SDD、先核实先例与生效路径、测试失败查根因、跨平台编码与换行保护、工具单一职责）
  - 通用中文文案规范（改前先指错、用词统一、去翻译腔、事实对齐代码）
  - 四通道知识分工与记忆写回三门禁

## 新电脑安装方式

1. 将本目录（`plugins/personal-core/`）复制或软链到 `~/.gemini/config/plugins/personal-core/`。
2. 在 Antigravity Customizations UI 中确认 `personal-core` 已开启（立即生效，无需重启）。

> [!NOTE]
> 如需补充个人所在地区、业务范围或专属前提，请仅在本地 `rules/AGENTS.md` 的「个人背景边界」条目中填写，**切勿将个人隐私或公司敏感规则提交到公开仓库**。
